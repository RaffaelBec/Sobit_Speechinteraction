# Sobit_Speechinteraction

The folder 'AssistanceFiles' holds code examples and information to help you with your project. Please leave this folder and the containing files intact.

Feel free to add more folders e.g. for examples / Code / further documentation. You can change the Readme and use this repo as your own - of course you can create multiple branches and you have the permissions to directly commit to the main branch.
Have fun coding!
